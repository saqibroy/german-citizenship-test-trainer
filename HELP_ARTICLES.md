## 🧠 How SRS Works

### What is Spaced Repetition?

**Spaced Repetition System (SRS)** is a learning technique based on cognitive science research. It's designed to help you remember information longer by showing you content at optimal intervals.

### The Science Behind SRS

**Key Principle:** The "forgetting curve" shows that we forget information over time unless we review it.

```
Memory Retention Over Time (Without Review):
100% ████████████ Day 1
 50% ██████       Day 2
 30% ████         Day 7
 10% ██           Day 30
```

**SRS Solution:** Review material just before you're about to forget it.

```
With Spaced Repetition:
100% ████████████ Review 1 (Day 1)
 95% ███████████  Review 2 (Day 3)
 98% ████████████ Review 3 (Day 7)
100% ████████████ Review 4 (Day 14)
100% ████████████ Mastered!
```

### How It Works in This App

#### 1. New Questions
- **Status:** 🆕 New
- **Never seen before**
- **Shown immediately** when you start training
- **Goal:** Get initial exposure

#### 2. Learning Phase
- **Status:** 📖 Learning
- **Seen 1-2 times**
- **Shown every session** until you demonstrate understanding
- **Goal:** Build initial memory

#### 3. Young Memory
- **Status:** 🌱 Young
- **Getting familiar**
- **Shown every few sessions**
- **Goal:** Strengthen memory

#### 4. Mature Memory
- **Status:** 💪 Mature
- **Know it well**
- **Shown weekly or less**
- **Goal:** Maintain memory

#### 5. Mastered
- **Status:** ⭐ Mastered
- **Fully learned**
- **Rare reviews only**
- **Goal:** Ensure retention

### How Questions Progress

**Moving Up (Correct Answer):**
```
🆕 New → 📖 Learning → 🌱 Young → 💪 Mature → ⭐ Mastered
```

**Moving Down (Incorrect Answer):**
```
⭐ Mastered → 📖 Learning (start over, but faster next time)
```

**Factors That Affect Progression:**

1. **Correctness:**
   - ✅ Correct = move up
   - ❌ Incorrect = drop to Learning

2. **Speed:**
   - ⚡ Fast (<5s) = strong knowledge, move up faster
   - 🐌 Slow (>20s) = uncertain, stay at current level longer

3. **Consistency:**
   - Answer correctly multiple times = progress faster
   - Answer incorrectly once = drop back (review needed)

### Why SRS is Effective

**Traditional Studying:**
- Study all 310 questions equally
- Waste time on questions you already know
- Neglect questions you struggle with
- Inefficient use of time

**With SRS:**
- Focus on what you need to learn
- Review at optimal intervals
- Efficient use of study time
- Better long-term retention

## 📚 How to Prepare for the Exam

### Understanding the Official Test

**Test Format:**
- **33 questions** total
  - 30 from general question pool
  - 3 from your state's question pool
- **60 minutes** time limit
- **Multiple choice** (4 options per question)
- **17+ correct answers** needed to pass (51.5%)
- **Language:** German only
- **Cost:** ~€25
- **Validity:** Lifetime (once passed)

**Question Categories:**
1. **Politics** (Leben in der Demokratie) - ~40%
2. **History** (Geschichte und Verantwortung) - ~25%
3. **People & Society** (Mensch und Gesellschaft) - ~20%
4. **Geography & Symbols** (Geografie & Symbole) - ~10%
5. **Law** (Recht und Alltag) - ~5%

### Study Timeline

#### **6+ Months Before Exam: Foundation Building**

**Daily Goal:** 10 questions (~5 minutes)

**Focus:**
- Learn all 310 questions at least once
- Build vocabulary
- Read all explanations carefully
- Don't worry about speed yet

**Strategy:**
- Training mode only
- Take notes on difficult concepts
- Use vocabulary section daily
- Start building study habit

**Expected Progress:**
- Month 1: ~60 questions introduced
- Month 2: ~120 questions introduced
- Month 3: ~180 questions introduced
- Month 4: ~240 questions introduced
- Month 5: ~300 questions introduced
- Month 6: All 310 seen, many in Learning/Young

#### **3-6 Months Before Exam: Strengthening**

**Daily Goal:** 20 questions (~10 minutes)

**Focus:**
- Move questions from Learning → Young → Mature
- Start taking practice quizzes
- Improve weak categories
- Build speed on familiar questions

**Strategy:**
- Daily training sessions
- 1 full quiz per week
- Review quiz results, focus on wrong answers
- Grammar lessons for comprehension

**Expected Progress:**
- 50%+ of questions in Young or higher
- Consistently scoring 20+/33 on quizzes
- Identified weak categories, working on them
- Study streak of 30+ days

#### **1-3 Months Before Exam: Mastery**

**Daily Goal:** 30 questions (~15 minutes)

**Focus:**
- Master weak categories
- Practice full quizzes regularly
- Improve time management
- Build confidence

**Strategy:**
- Daily training sessions
- 2-3 full quizzes per week
- Time yourself on quizzes (practice pacing)
- Flashcards for final review

**Expected Progress:**
- 60%+ of questions Mature or Mastered
- Consistently scoring 25+/33 on quizzes
- All categories above 70% accuracy
- Ready to schedule exam

#### **Last Month Before Exam: Polish & Practice**

**Daily Goal:** 40 questions (~20 minutes)

**Focus:**
- Polish remaining weak spots
- Daily quiz simulations
- Perfect timing (finish in <60 minutes)
- Mental preparation

**Strategy:**
- Daily training (40 questions)
- Daily quiz (simulate real exam)
- Review any remaining Learning questions
- Stay calm, trust your preparation

**Expected Progress:**
- 80%+ of questions Mature or Mastered
- Consistently scoring 28+/33 on quizzes
- Finish quizzes in 30-45 minutes
- 100% confident for exam day

### Common Mistakes to Avoid

❌ **Cramming the Night Before**
- SRS requires spaced learning
- You can't learn 310 questions in one night
- Start months in advance

❌ **Only Doing Quizzes**
- Quizzes test knowledge
- Training builds knowledge
- You need both!

❌ **Ignoring Weak Categories**
- Easy to avoid what you don't know
- Exam will include all categories
- Focus on weaknesses

❌ **Memorizing Without Understanding**
- Questions may be worded differently
- Understand concepts, not just answers
- Use explanations and vocabulary

❌ **Not Taking Breaks**
- Your brain needs rest
- Sleep helps consolidate memory
- Don't burn out

❌ **Losing Confidence**
- Everyone struggles at first
- Progress is gradual
- Trust the SRS algorithm

### Exam Day Preparation

**The Day Before:**
- Light review only (don't cram)
- Get good sleep (8+ hours)
- Prepare documents (ID, invitation)
- Plan your route to test center

**Exam Day:**
- Arrive 15 minutes early
- Bring ID and invitation
- Bring water (if allowed)
- Use restroom before exam
- Stay calm, breathe

**During the Exam:**
- Read questions carefully
- Eliminate obviously wrong answers
- Don't spend too long on one question
- Answer all questions (no penalty for guessing)
- Review answers if time allows
- Trust your preparation

**After the Exam:**
- Results usually immediate
- If passed: Celebrate! 🎉
- If failed: Don't be discouraged
  - You can retake it
  - Review your weak areas
  - Come back stronger

## 🔧 Troubleshooting Common Issues

### Progress Not Saving

**Symptoms:**
- Answered questions but progress resets
- Quiz results disappear
- Badges don't persist
- Study streak resets unexpectedly

**Causes:**
1. Using private/incognito mode
2. Browser blocking localStorage
3. Switching browsers/devices
4. Browser cache cleared
5. Browser storage full

**Solutions:**

**1. Check Browser Mode:**
- Don't use private/incognito mode for studying
- Use normal browser mode
- Progress saves to localStorage (cleared in private mode)

**2. Check localStorage Permission:**
- Chrome: Settings → Privacy → Site Settings → Cookies
- Firefox: Preferences → Privacy → Custom → Cookies
- Ensure "Allow sites to save data" is enabled

**3. Use Same Browser/Device:**
- Progress is per-browser
- Switching browsers = different progress
- Solution: Export data from old browser, import to new

**4. Browser Storage Full:**
- Clear old data from other sites
- Chrome: Settings → Privacy → Clear browsing data
- Keep cookies for this site
- Storage needed: ~5-10 MB

**5. Backup Regularly:**
- Settings → Export My Data (weekly)
- Keep JSON file safe
- Restore anytime with Import Data

**Prevention:**
- Install as PWA (more stable)
- Export data monthly
- Use same browser consistently
- Bookmark the site

### Study Streak Issues

**Symptom:** Streak not updating or resets unexpectedly

**Common Causes:**

**1. Didn't Answer Questions:**
- Opening app doesn't count
- Must answer at least 1 question
- Training, Quiz, or Flashcards all count

**2. Missed a Day:**
- Studied Monday, skipped Tuesday, studied Wednesday
- Streak resets to 1 on Wednesday
- No exceptions (except grace period)

**3. Grace Period Confusion:**
- Study at 11:30 PM Tuesday
- Counts until 4:00 AM Wednesday
- After 4 AM = new day required
- Designed for late-night learners

**4. Timezone Changes:**
- Traveling across timezones?
- App uses browser local time
- May affect streak calculation
- Export data before travel

**Solutions:**

**To Maintain Streak:**
- Study same time daily (build habit)
- Set daily reminder (phone alarm)
- Even 1 question counts
- Use grace period wisely

**If Streak Resets:**
- Don't be discouraged
- Start again
- Previous longest streak saved
- Focus on consistency, not number

**To Check Streak:**
- Homepage shows current streak
- Stats page shows longest streak
- Last study date in localStorage (check browser console)

### Badges Not Appearing

### Can't Import Data

**2. File Corrupted:**

### App Running Slow

**Symptoms:**
- Slow page loads
- Laggy animations
- Delayed responses

**Causes:**
1. Old browser version
2. Too many browser tabs open
3. Low device memory
4. Large browser cache
5. Outdated device

**Solutions:**

**1. Update Browser:**
- Chrome: Menu → Help → About Google Chrome
- Firefox: Menu → Help → About Firefox
- Safari: macOS Update
- Always use latest version
