## 📚 What is this?

The **German Citizenship Test Trainer** is a free, open-source web application designed to help you prepare for the German naturalization test (Einbürgerungstest). Using proven spaced repetition algorithms, we make learning more efficient and help you retain information longer.

### ✨ Key Features

- **🎯 310 Official Questions** - Complete question pool from the official test
- **🧠 Smart Learning Algorithm** - Spaced Repetition System (SRS) adapts to your learning
- **📝 Full-Length Practice Quizzes** - Simulate the real exam (33 questions, 60 minutes)
- **🗂️ Organized by Category** - Politics, History, People & Society, Geography, Law
- **📖 Vocabulary Training** - 150+ essential German citizenship terms
- **📚 Grammar Lessons** - 12 comprehensive German grammar lessons
- **🎴 Flashcards** - Learn with interactive flashcards (swipe on mobile!)
- **📊 Progress Tracking** - See your improvement over time
- **🏆 Achievement Badges** - Stay motivated with 30+ badges
- **📱 Mobile-First Design** - Perfect on phones, tablets, and desktops
- **🌐 Bilingual** - Full support for German and English
- **💾 Offline Support** - Install as PWA, works without internet
- **🔒 Privacy-First** - Your data stays on your device (GDPR compliant)

## 🧠 Understanding the SRS Algorithm

### What is Spaced Repetition?

**Spaced Repetition System (SRS)** is a learning technique that helps you remember information longer by:

1. Showing you **new questions** frequently
2. Gradually **spacing out reviews** of questions you know
3. **Bringing back** questions you struggle with more often

### SRS Levels in This App

Each question progresses through **5 levels**:

| Level | What it means | Review Frequency |
|-------|---------------|------------------|
| 🆕 **New** | Haven't seen this yet | Shown immediately |
| 📖 **Learning** | Seen 1-2 times, still learning | Every session |
| 🌱 **Young** | Getting familiar | Every few sessions |
| 💪 **Mature** | Know it well | Weekly |
| ⭐ **Mastered** | Fully mastered | Rare reviews |

### How Questions Move Between Levels

- ✅ **Answer correctly** → Question moves up (or stays if mastered)
- ❌ **Answer incorrectly** → Question drops back to learning
- ⏱️ **Answer quickly** → Shows strong knowledge, level up faster
- 🐌 **Answer slowly** → May need more review

**Goal:** Get all 310 questions to **Mastered** level! 🎯

## 🎯 How to Prepare for the Exam

### Recommended Study Plan

#### **6+ Months Before Exam**
- **Daily Goal:** 10 questions/day (~5 minutes)
- **Focus:** Build foundation, learn all questions once
- **Strategy:** Training mode only, read explanations carefully

#### **3-6 Months Before Exam**
- **Daily Goal:** 20 questions/day (~10 minutes)
- **Focus:** Review weak categories, start quizzes
- **Strategy:** Mix of training and 1 quiz per week

#### **1-3 Months Before Exam**
- **Daily Goal:** 30 questions/day (~15 minutes)
- **Focus:** Practice quizzes, master weak areas
- **Strategy:** 2-3 quizzes per week, daily training sessions

#### **Last Month Before Exam**
- **Daily Goal:** 40 questions/day (~20 minutes)
- **Focus:** Full quiz simulations, polish remaining questions
- **Strategy:** Daily quiz + training for weak areas

### Tips for Success

✅ **Be Consistent** - Study a little every day (better than cramming)  
✅ **Take Full Quizzes** - Practice under real exam conditions  
✅ **Learn from Mistakes** - Read explanations for wrong answers  
✅ **Focus on Weak Categories** - The app shows you which need work  
✅ **Use Vocabulary** - Understand key terms in German  
✅ **Review Grammar** - Better comprehension = better scores  
✅ **Track Your Streaks** - Build a habit, earn badges  
✅ **Don't Stress** - The test is designed to be passable with study  

### What to Expect on Test Day

- **33 questions** (30 general + 3 state-specific)
- **60 minutes** total time
- **17 correct answers** needed to pass (51.5%)
- **Multiple choice** (4 options per question)
- **Paper or computer** (varies by location)
- **German language** (no translations provided)

## 🔧 Troubleshooting

### Common Issues

#### **❓ Questions/Progress Not Saving**

**Solution:**
1. Check browser allows localStorage
2. Don't use private/incognito mode for studying
3. Export your data regularly (Settings → Export My Data)

#### **❓ Study Streak Not Updating**

**Solution:**
- Study streak updates when you **answer questions** (not just open app)
- Has **4-hour grace period** (studying at 11:30 PM counts for next day until 4 AM)
- Check if you studied yesterday (1 day gap resets streak)

#### **❓ Badges Not Appearing**

**Solution:**
- Badges appear on **Homepage** (recent 3) and **Stats page** (all)
- Must complete the required action (e.g., answer X questions)
- Refresh page if just earned a badge

#### **❓ Quiz Timer Not Working**

**Solution:**
- Timer starts when you click "Start Quiz"
- Continues even if you close browser (saved in localStorage)
- Completes automatically when 60 minutes elapses

#### **❓ App Not Working Offline**

**Solution:**
1. Visit app while online first (downloads resources)
2. Install as PWA (see installation instructions above)
3. Service worker needs to cache files (happens automatically on first visit)

#### **❓ Can't Import Data**

**Solution:**
- File must be JSON format (exported from this app)
- File must have `exportDate` field (validation check)
- Try exporting again, then importing the new file

#### **❓ Language Changed Accidentally**

**Solution:**
- Settings page → Choose your preferred language
- Or click flag icon (🇩🇪/🇬🇧) in top navigation

## 🎓 About the German Citizenship Test

### Official Information

**Test Name:** Einbürgerungstest  
**Authority:** Bundesamt für Migration und Flüchtlinge (BAMF)  
**Official Website:** [bamf.de](https://www.bamf.de/DE/Themen/Integration/TraegerLehrFachkraefte/Integrationskurse/Abschlusspruefung/Einbuergerungstest/einbuergerungstest-node.html)

### Test Details

- **Total Questions:** 33 (30 general + 3 state-specific)
- **Pass Score:** 17 correct (51.5%)
- **Time Limit:** 60 minutes
- **Format:** Multiple choice (4 options)
- **Language:** German only
- **Cost:** €25 (may vary)
- **Validity:** Lifetime (once passed)

### Question Pool

- **General Questions:** 300 questions (same nationwide)
- **State Questions:** 10 per state (3 appear on your test)
- **Total Pool:** 310 questions (300 + 10 for your state)

**This app covers all 310 questions!**

### Who Needs This Test?

Required for:
- German citizenship application (Einbürgerung)
- Some integration course completions

**Exemptions:**
- Children under 16
- People with physical/mental disabilities
- Completed German school education
- Academic degrees from German institutions

Check with your local Ausländerbehörde (foreigners office) for specific requirements.
